운행표 데이터 편집기 - 설치 파일 만들기 / 업데이트 방법
=====================================================

[처음 한 번 준비]  (설치 파일을 만드는 PC 한 대만)
 1. 파이썬 설치 (python.org) - 설치 화면에서 "Add python.exe to PATH" 체크
 2. Inno Setup 6 설치 (https://jrsoftware.org/isdl.php)
 3. 이 폴더에 둘 것: pdf_data_editor24.py, setup.iss, release.py, release.bat
    (선택) 기본데이터.db : 프로그램 ⚙️ 설정 > [설치용 기본 데이터 파일 만들기]
    (선택) icon.ico      : 프로그램 아이콘

[설치 파일 만들기]
 release.bat 더블클릭
  -> Output\RunSheetEditor_setup_2.1.0.exe 가 생깁니다.
  -> 마지막에 "업데이트 폴더"를 물으면 Enter(C:\RADIO\업데이트) 또는 공유 폴더 경로 입력

[각 PC에 처음 설치]
 RunSheetEditor_setup_버전.exe 실행
  -> C:\RADIO 에 설치, 바탕화면에 "운행표 편집기" 바로가기
  -> 예전에 쓰던 기록(사용자 폴더)이 있으면 처음 켤 때 옮길지 물어봅니다.

[업데이트 (새 버전 배포)]
 1. 새 .py 파일(예: pdf_data_editor25.py)을 이 폴더에 넣는다
    (파일 안의 APP_VERSION 이 예전보다 커야 함 - 예: "2.1.0" -> "2.2.0")
 2. release.bat 더블클릭 -> 업데이트 폴더에 올리기
 3. 각 PC는 프로그램을 켤 때 "새 버전이 있습니다" 안내 -> [예] 누르면
    백업 -> 프로그램 닫힘 -> 설치 -> 다시 켜짐 (기록·설정 그대로)
 ※ 여러 PC: 프로그램 ⚙️ 설정 > 업데이트 폴더를 공유 폴더(예: \\서버\RADIO\업데이트)로
    지정하고, release.bat 에서도 같은 공유 폴더에 올리세요.
 ※ 안내 없이 바로 하려면: 설정 > [지금 확인]

[폴더]
 C:\RADIO\프로그램   프로그램 (업데이트 때 교체)
 C:\RADIO\데이터     pdf_data_editor.db(기록·미리 만든 데이터), settings.json
 C:\RADIO\백업       날짜별 자동 백업 (복원: 백업 파일을 데이터 폴더에 pdf_data_editor.db 이름으로 복사)
 C:\RADIO\업데이트   기본 업데이트 폴더
 프로그램을 제거해도 데이터·백업 폴더는 남습니다.
