운행표 데이터 편집기 - 설치 꾸러미 만들기 / 설치 / 업데이트
(GitHub 가입, Inno Setup 설치 필요 없음)
=====================================================

[A. 설치 꾸러미 만들기]  인터넷 되는 윈도우 PC 한 대에서, 새 버전 낼 때만
 1. https://winpython.github.io/ 에서 WinPython(64bit, Python 3.12 또는 3.13, "dot" 판이면 충분)을 받습니다.
    - 설치가 아니라 압축 파일(자체 압축 풀림 exe)입니다. 관리자 권한·가입 필요 없음.
 2. 받은 파일을 실행해 "이 폴더 안에" 풀어 둡니다.  (예: 이 폴더\WPy64-31290\...)
 3. (선택) 기본데이터.db 를 이 폴더에 둡니다.
      프로그램 ⚙️ 설정 > [기본 데이터 파일 만들기 (다른 PC용)] 로 만든 파일
 4. release.bat 더블클릭
      -> 인터넷에서 필요한 것을 받아 프로그램을 만들고
      -> Output\RunSheetEditor_버전.zip 과 version.json 이 생깁니다.
      -> 마지막에 업데이트 폴더를 물으면 Enter(C:\RADIO\업데이트) / 공유 폴더 경로 / n(건너뛰기)
    ※ 파이썬이 이미 설치된 PC라면 WinPython 없이 그냥 release.bat 실행

[B. 각 PC에 설치]  파이썬 필요 없음
 1. RunSheetEditor_버전.zip 을 USB·메일·공유 폴더로 옮겨 압축을 풉니다.
 2. '설치.bat' 더블클릭
      -> C:\RADIO 에 설치, 바탕화면·시작 메뉴에 [운행표 편집기] 바로가기
      -> 처음 켤 때: 예전 기록이 있으면 옮길지 묻고, 없으면 기본 데이터로 시작
 3. 기본 데이터를 나중에 넣으려면: ⚙️ 설정 > [기본 데이터 가져오기] 에서 기본데이터.db 선택
      (없는 것만 더함, 기존 자료는 그대로)

[C. 업데이트]
 1. 새 .py 파일(APP_VERSION 을 올린 것)을 이 폴더에 넣고 release.bat 실행 -> 업데이트 폴더에 올리기
 2. 각 PC는 프로그램을 켤 때 "새 버전이 있습니다" -> [예]
      -> 기록 저장 -> 백업 -> 프로그램 닫힘 -> 교체 -> 다시 켜짐 (기록·설정 그대로)
 ※ 여러 PC: ⚙️ 설정 > 업데이트 폴더를 공유 폴더(예: \\서버\RADIO\업데이트)로 지정하고
    release.bat 에서도 같은 곳에 올리세요.
 ※ 공유 폴더가 없으면: 새 zip 을 각 PC에서 풀고 '설치.bat' 를 다시 실행해도 됩니다 (데이터 그대로).

[폴더]
 C:\RADIO\프로그램   프로그램 (업데이트 때 교체)
 C:\RADIO\데이터     pdf_data_editor.db(기록·미리 만든 데이터), settings.json
 C:\RADIO\백업       날짜별 자동 백업 (복원: 백업 파일을 데이터 폴더에 pdf_data_editor.db 이름으로 복사)
 C:\RADIO\업데이트   기본 업데이트 폴더

[참고]
 - setup.iss 는 Inno Setup 이 설치된 PC에서만 쓰입니다 (있으면 setup.exe 도 같이 만듦, 없어도 됨).
 - 윈도우가 '알 수 없는 게시자' 경고를 띄우면 [추가 정보] > [실행].
